# 料力榜设计文档

## 产品目标

将持续维护的料包测评表转为易浏览、易分享的中文排行榜。访客可快速发现高分料包，并查看色香味、还原度、易用性与简短评语。

## 产品边界

- 使用原生 HTML、CSS、JavaScript 构建的静态站点。
- 数据在构建时写入页面；当前不接数据库、登录、后台或实时同步。
- 空字段以 `-` 呈现，并在排序时始终置后。
- 视频链接只在数据源提供时展示为跳转入口；当前不抓取或展示视频封面。

## 页面与交互

- 顶部导航：标准头像、料力榜名称与移动端口号。
- 精选区：展示前三名；冠军卡片上方使用皇冠标识。
- 筛选区：支持关键词搜索、品牌多选下拉框（含全选和取消全选）与排序。
- 完整榜单：桌面端可通过表头排序；移动端为可展开的单列卡片。
- 移动端展开卡片：分数与展开状态在首行右侧；有视频时“观看视频”与评语评级同行右对齐。

## 视觉系统

整体使用温柔、平面、圆弧的料理奖台风格，参考头像插画的配色：

- 奶油黄：`#F0F0C0`，用于背景。
- 珊瑚粉：`#E08070`，用于冠军与主强调。
- 柔肤色：`#F0E0D0`，用于卡片和浅色分区。
- 腮红粉：`#F0A090`，用于交互状态与次级强调。
- 深墨黑：`#101010`，用于文字与轮廓。
- 雾灰：`#D0D0D0`，用于边界和次要信息。

以大圆角、清楚的层级和留白组织内容；不使用未经提供的产品图、品牌图标或营销文案。

## 数据流

本地 `料力榜.xlsx` 由 `scripts/build_data.py` 读取，生成 `dist/data.js` 与无 JavaScript 时的基础榜单。浏览器内完成搜索、筛选、排序与展开，不调用后端服务。

源表属于私有维护资料，不提交到公开仓库；`dist/data.js` 是站点运行必需的静态展示数据。
