# 料力榜更新与打包指南

本指南用于把最新版测评表更新到网站，并生成供移动端上传的离线包。

## 1. 准备数据表

将最新 Excel 放到项目根目录，文件名固定为 `料力榜.xlsx`。该文件已被 `.gitignore` 排除，不能提交到公开仓库。

支持的字段为：日期、期数、品牌、料包、色香味、还原度、易用性、料力评分、评语、视频链接。品牌或料包为空的记录不会进入榜单；分数字段空白、`-` 或公式错误会显示为 `-`，并在排序中保持最后。

## 2. 生成网页数据

在项目根目录执行：

```bash
uv run python scripts/build_data.py
```

此命令会更新：

- `dist/data.js`：供页面使用的排行榜数据。
- `dist/index.html`：无 JavaScript 时展示的基础榜单。

## 3. 本地检查

运行测试：

```bash
uv run python -m unittest tests/test_build_data.py -v
node --test tests/app.test.mjs
```

如需人工浏览：

```bash
python3 -m http.server 8000 --directory dist
```

访问 `http://localhost:8000`，并检查桌面与移动宽度下的搜索、品牌筛选、排序、展开详情及视频链接。

## 4. 发布网站

确认 `dist/` 更新后，提交页面代码与文档；不要提交 `料力榜.xlsx` 或 `artifacts/` 下的压缩包。发布时将 `dist/` 作为静态目录部署到现有 Sites 项目。

## 5. 制作移动端离线包

离线包工作目录为 `artifacts/liaolibang-minitool/`，压缩产物放在 `artifacts/`。两者均不提交到公开仓库。

生成离线包数据：

```bash
uv run python scripts/build_data.py 料力榜.xlsx artifacts/liaolibang-minitool/data.js
```

打包时确保资源完全本地化、无外部网络依赖，并将该目录中的文件直接压缩到 ZIP 根目录。例如：

```bash
cd artifacts/liaolibang-minitool
zip -r ../liaolibang-minitool-版本号.zip . -x '*.DS_Store'
```

上传前先按 [README 的安装说明](../README.md#移动端离线包校验工具)下载 `minitool-zip-builder 1.7.0`，读取其 `SKILL.md` 并使用审计脚本审核 ZIP。

该 skill 的交付要求是：将同一 ZIP 上传到创服平台，先在平台模拟器完成完整功能验证，再分别使用 Android 与 iOS 真机扫码验证。它不会要求自动登录、上传或启动真机，也不会因未完成这三项人工验证而阻塞 ZIP 的生成；这些步骤应作为发布前的人工验收。

## 6. 同步公开仓库

仅提交页面源码、`dist/` 的可部署资源、测试与 `docs/` 文档。提交前检查：

```bash
git status --short
git diff --check
```

确认没有 `料力榜.xlsx`、`artifacts/`、系统缓存或本地配置后再推送。
